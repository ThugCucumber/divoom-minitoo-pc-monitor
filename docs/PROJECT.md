# О проекте и публичной версии

Проект вырос из настройки одного Windows-ПК и Divoom MiniToo. Его практическая цель — вынести основные показатели компьютера на небольшой настольный экран и переключать страницы джойстиком устройства.

Исходная установка: AMD Ryzen 7 7700, NVIDIA GeForce RTX 5060 Ti, Python 3.14, Bluetooth SPP COM3 и USB HID. Локальные рабочие записи фиксировали успешную передачу изображений, переключение джойстиком и восстановление worker supervisor'ом. Длительная стабильность и совместимость с другими устройствами систематически не подтверждались.

Публичная копия сохраняет актуальные страницы Overview / Network / Clock и основной путь передачи. Для переносимости добавлены JSON-конфигурация, зависимости, скрипты автозапуска без личных путей, тесты и демонстрационные изображения. Из вспомогательного протокольного файла оставлены функции формирования пакетов и кодирования изображения, которые нужны монитору; старые экспериментальные команды CLI не входят в публичный интерфейс.

В публикацию не включены журналы, реальные статусы, захваты HID, персональные Windows-пути, диагностическая хронология с идентификаторами, резервные копии, APK и декомпиляция. Изображения построены на синтетических данных.

Как и сказано в начале README, и сам проект, и его подготовка к публикации навайбкодены с помощью ИИ. Наличие тестов не означает полного аудита: это исходная точка для дальнейшей проверки и доработки.
